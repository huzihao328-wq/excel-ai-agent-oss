# Excel AI Agent

在 Excel 任务窗格里运行的 AI 智能体插件：用自然语言完成数据分析、清洗、跨 Sheet 合并、公式编写、格式化和图表，就像在 VS Code 里使用 AI Agent 一样。

> **给 Agent：** 安装、侧载、注册、卸载或打包本插件之前，必须先完整阅读 [`INSTALL.AGENT.md`](INSTALL.AGENT.md)，不要跳步。人类用户看下面的「快速开始」即可。

## 功能特性

- **Agent 自主工作流**：模型先查看工作簿结构，再按需读取数据、执行操作、验证结果，全程工具调用过程在界面上可视化展示。
- **60+ 个工具**：结构概览、区域读写、公式批量填充、原生复制/转置/向下填充、跨表查找匹配（XLOOKUP）、拆列/拼列、列清洗（去空格/金额/日期）、公式转成值、一键整理格式、删除空行、冻结窗格、查找替换、去重、重命名/复制 Sheet、列统计、条件格式、数据验证（下拉框/范围限制/防重复）、隐藏与取消隐藏、合并单元格/换行/列宽行高、新建/删除 Sheet、插入/删除行列、格式化、排序（可按表头、多列）、图表、Excel 表/自动筛选/透视表、外部文件读取与导入、长期记忆与技能库。大表统计、复制和跨表匹配不再把整表读进模型。
- **整表处理**：分组汇总（可按年/季度/月/周分段）、两表对账（多键、金额误差、重复键求和）、多表按表头对齐纵向合并、按列拆成多张表。插件在本地分块读全表计算，结果写到新 Sheet，不受 5000 单元格抽样限制；文本数字、空键、重复键等会在结果里明确提示。
- **报表整理**：
  - **拆合并补空白**：系统导出的报表里分类列用了合并单元格、下面全是空白，一句「取消合并并填充」就把每格补上所属的值（只动跨多行的合并，单行标题保持原样）；也能把指定列的空白按上方/左侧的值或固定值（如 0）填满。可撤销。
  - **宽表转长表**：1月～12月、各门店各占一列的横排表，转成「标识列 + 属性 + 值」的长表写到新 Sheet，后面直接做汇总和透视。
  - **打印排版**：横向/纵向、A4/A3、所有列缩到一页宽、每页重复打印表头、窄边距、水平居中、页眉标题和「第 X 页，共 Y 页」页码，一句话设好。
  - **目录页**：Sheet 多时生成放在最前面的「目录」，每张表一行、点一下跳转，附数据区域和行数；再说一次就原地刷新。
- **信息提取**：从备注、地址这类文本列里抠出手机号（含 +86、带空格横线的写法）、邮箱、身份证号、金额数字、日期、网址、中文、英文，写到右侧新列；由身份证号推出生日期、性别、周岁年龄并做校验位检查，被存成数字、丢了末几位的身份证会单独提示。列清洗新增全角转半角、去掉所有空格（「张 三」→「张三」）、英文大小写、金额转人民币大写（壹仟贰佰叁拾肆元伍角陆分）。
- **版本比对**：同一张表的两个版本（改前改后、上月本月、两份导出）逐格比对，差异清单（变化、行、列、原值、新值、位置）写到新 Sheet；给工号、订单号这类键就按键对齐，行顺序变了、插删行也能比；可选在新版本上把改过的格标黄、新增行标绿。
- **计算脚本兜底**：专用工具和公式都做不到的逻辑（复杂文本解析、模糊匹配、多条件打标、自定义分摊等），AI 会写一段 JS 在隔离沙箱（一次性 Web Worker）里跑：插件读全表、结果直接写到新 Sheet，数据不经过对话。沙箱里移除了联网、`eval`/`Function`、定时器等一切非计算能力，也碰不到 Excel 对象和 API Key；默认 15 秒超时自动终止。
- **数据体检**：一句"做个数据体检"，自动扫描缺失值、重复行、类型不一致、离群值和首尾空格，生成报告 Sheet；对话里出现可勾选的问题卡片，你勾选哪几类、AI 才修哪几类。
- **公式诊断**：`diagnose_errors` 扫描整张表的公式错误并按"类型 + 公式模式"聚类，先解释每类错误的根因、给出修复方案，你确认后才动手改。
- **批量任务**：🗂 面板里对多个附加文件执行同一条指令（如"清洗后导入"），每个文件独立跑一遍 Agent，结果写入当前工作簿并带文件标识，逐文件显示进度与工具轨迹。
- **操作时间线**：🕘 面板按时间倒序回放 AI 的每次改动（写入/结构/格式/导入/图表），点击任意一步可查看"修改前 vs 修改后"对比，可撤销的步骤还能直接回退。
- **结果引用**：AI 生成的汇总表/图表/透视自动登记为"最近产出"随上下文注入，"基于刚才的结果再按月份拆分"这类追问能直接定位到上次产出继续加工；输入框上方也会显示引用胶囊，点一下插入到指令里。
- **常用指令**：内置周报、月度环比、两表核对、金额核对、名单清洗、按类别拆表、拆合并补空白、宽表转长表、身份证信息、版本比对、打印排版等高频模板；自己的指令也能保存、搜索、编辑，一键填入或直接运行。
- **技能直接套用**：技能库支持按名称、触发词和步骤搜索，展开后可把完整流程直接套用到当前任务，再补充本次具体要求。
- **升级继承**：全局记忆、技能库、模型和自定义指令写在本机用户目录（与插件源码分开），换版本或重装后自动接上，不会从零开始。本工作簿的约定仍跟 xlsx 走。
- **安全机制**：
  - 覆盖已有数据、删除行列/Sheet、清空区域等破坏性操作，会弹出确认卡片并展示"原内容 vs 将写入"预览，你点"允许"才会执行；也可以"拒绝并说明"告诉 AI 换个做法，或勾选"本次任务中同类操作不再询问"；
  - 写入类操作自动记录快照，底部"回退"栏可撤销上一步，展开后可逐步撤回或整段恢复到任务开始；
  - 输入框上方的快捷操作：带 ▶ 的是只读操作，点了直接执行；其余只填入输入框，你检查、补充后再发送；
  - 分析产出默认写入新 Sheet，不动原始数据。
- **执行中随时纠正**：任务执行时在输入框写补充说明按 Enter，AI 在下一步之前就能看到并调整；点"排队"则等任务完成后再发。方向选择卡片可以写"其他做法"。任务结束后，执行过程折叠成"已执行 N 步"，失败的步骤仍露在外面。
- **随手的小细节**：回复里写的位置（如 `汇总!A1:D12`、「汇总」）点一下就在 Excel 里选中；公式代码块右上角一键复制；点输入框下方的工作表胶囊把当前选区地址插到光标处；没发出去的草稿关掉任务窗格也不丢；模型或某一步跑得久时显示已用时间。
- **上下文感知**：自动把当前活动 Sheet、选区（可含选区内容）随消息发给模型，"处理我选中的这块数据"这类话它能直接听懂。
- **模型无关**：支持任何 OpenAI 兼容接口——DeepSeek、OpenAI、Moonshot、通义千问、本地 Ollama 等，内置一键预设。API Key 只存在本机。限流、服务端 5xx 或短暂断网会自动重试；已经开始往界面推文字后不再重试，避免重复输出。

## 快速开始（一次性安装，之后打开 Excel 即用）

```powershell
npm install
npm run install-addin
```

`install-addin` 会依次完成：

1. **构建**生产版本到 `dist/`；
2. **注册**插件到当前用户的 Excel（按钮常驻开始选项卡，无需每次侧载）；
3. **设置开机自启动**的本地静态服务（`https://localhost:3000`，隐藏窗口运行），并立即启动。

完成后重启 Excel，开始选项卡会出现 **AI Agent** 按钮，以后开机即可直接使用，不需要再运行任何命令。

卸载：`npm run uninstall-addin`（移除注册和自启动项）。

> 修改代码后运行 `npm run build` 刷新产物即可，服务无需重启。日常开发调试仍可用 `npm start`（会自动放行 localhost 回环，不再弹出确认；带热更新的 dev server 与静态服务共用 3000 端口，二者同时只能跑一个）。

### 手动侧载（备选方案）

Excel 网页版：插入 → 加载项 → 上传我的加载项 → 选择 `manifest.xml`。
Windows 桌面版也可用共享文件夹方式：把 manifest 所在文件夹设为共享，在 信任中心 → 受信任的加载项目录 中添加该路径后重启 Excel。

### 配置模型

打开任务窗格（开始选项卡 → AI Agent 按钮），点右上角 ⚙：

1. 选一个服务商预设（或手动填 API 地址）；
2. 填入 API Key；
3. 点"测试连接"，查看普通对话、工具调用往返和上下文探测结果，再保存。测试工具是虚拟工具，不读写工作簿；会额外产生少量模型请求。普通对话成功不代表工具能力通过。

「上下文窗口」留空时使用自动探测：区分接口返回、运行配置和模型名估算；Ollama 优先读取当前运行的窗口或 `num_ctx`。接口没有提供实际限制时，估算值仅用于保守预算。手动填写的值优先，点击「探测」会刷新缓存但不会覆盖手动值；旧版本曾自动填入的数值可清空以恢复自动。请求预算包含工具定义、实时上下文和输出预留，历史过长会先压缩；接口明确报告超限时进一步压缩并最多重试一次。无法压缩到预算内时会提示调整，不会重复已完成的改表操作。

工具参数错误会返回必填/允许字段；同批前置工具失败后，余下调用先跳过，由模型按实际结果调整。相同参数连续失败两次后会阻止重复执行。

> 使用 Ollama 本地模型时，需要以 `OLLAMA_ORIGINS=*` 启动 Ollama 以允许跨域请求。

### 开始使用

试试这些指令：

- "把 Sheet1 和 Sheet2 按订单号合并到新表"
- "统计销售表里每个地区的总金额，做成汇总表并画柱状图"
- "检查这个表有什么数据质量问题，清洗后放到新 Sheet"
- 选中一块区域后说："把这块数据转置后放到 F1"
- "不要读全表，先告诉我每列有多少空值和金额合计"
- "把报名名单里的重复行去掉，保留第一次出现的"

## 构建生产版本

```powershell
npm run build
```

产物在 `dist/`。本机持久安装不要改 `manifest.xml` 里的 `https://localhost:3000`。若要部署到自己的 HTTPS 静态服务器再分发，才把该地址全部换成你的站点。

## 打安装包

默认打**内网离线包**（含编好的 `dist`、本地 Office.js、`runtime/node.exe`），目标机不需要访问 npm：

```powershell
npm run pack
```

得到 `pack/excel-ai-agent-<version>.zip`。拷到内网机器解压后双击 `install.cmd`。

仅源码（接收方必须能 `npm install`）：`npm run pack:src`。

步骤与排障见 `INSTALL.AGENT.md`。

## 跨文件读取

Office.js 只允许插件操作当前打开的工作簿，本插件通过**附加文件**绕过这一限制：

- 点击输入框左侧的 📎 按钮，或直接把文件**拖进任务窗格**，即可附加 `.xlsx / .xls / .xlsm / .csv` 文件（≤20MB，CSV 自动识别 UTF-8/GBK 编码）；附加文件会保存在本机，**关闭任务窗格后自动恢复**。
- 附加后 AI 可以查看文件结构（`list_external_files`）、读取数据（`read_external_sheet`）、或把整个工作表导入当前工作簿（`import_external_sheet`）后用全部工具处理；
- 处理完可以说「导出成 Excel」：`export_file` 会下载当前工作簿副本（含格式/图表）。菜单里也有「导出工作簿」。插件不能直接改磁盘上的原路径，下载后请另存。
- 典型用法：附加 `02-dirty-data.xlsx` 后直接说"把这个文件清洗后和 Sheet1 合并"。

## 已知限制

- 插件无法直接覆盖磁盘上的原文件路径；导出为下载副本后请另存或手动替换。
- 删除 Sheet、删除行列无法通过插件撤销（会先请求确认）。
- 单次完整读取上限约 5000 单元格；更大的表会自动抽样，并可用列统计、原生复制、查找匹配和分页读取。
- 分组汇总、对账、多表合并、按列拆表单次最多处理 100 万个单元格，结果是静态值（不随源表自动刷新，需要可刷新的汇总请用透视表）。
- 跨表合并写成查找公式（XLOOKUP），不会把整张查找表读进对话。
